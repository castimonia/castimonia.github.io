C++가 보이는 그림책

innominata May 4, 2006
C++가 보이는 그림책샀다.

[ 이미지를 통해 C++ 프로그래밍의 기본 지식과 개념을 배울 수 있는 책 ]

C++ 언어의 가장 큰 특징인 객체 지향 프로그래밍은 처리와 데이터를 그룹화하여 그것들을 조합해 프로그램을 만들어 가는 방법으로 프로그램을 더욱 직관적으로 기술할 수 있고, 여러 사람이 함께 프로그램을 개발하기에도 적합합니다. 그러나 한편으로는 추상적인 개념들이 많고, 다른 객체 지향 프로그래밍 언어에 비해 포인터가 관련되는 경우가 많아 개념을 파악하고 이해하기가 더욱 어렵습니다.

이 책은 C++ 언어의 새로운 개념들에 대해서, 문장보다는 이미지를 전면에 내세워 해설하였습니다. 그리고 C++ 언어의 특징인 객체 지향적 프로그래밍 사고법을 시각적으로 정리하여, 좀더 구체적인 이미지를 파악할 수 있게 하였습니다. 따라서 C++ 언어를 어느 정도는 사용할 수 있지만 클래스나 오브젝트에 대해 잘 이해하지 못했던 분이나 C++ 언어의 새로운 개념을 어렴풋하게만 이해했던 분들에게는 분명히 정확한 이미지가 전해질 것입니다.

한 번 C++ 언어에 도전했다가 어려운 개념들에 막혀 잠시 책을 덮으셨던 분이나 C++ 언어에 새롭게 도전하시려는 분들에게 많은 도움이 될 것입니다.
