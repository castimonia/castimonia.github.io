태터 업글 1.02 -> 1.03

innominata 3월 25, 2006

뭐.. 깐지 얼마나 되었다고, 벌써 업글도 하고..
암튼..어려운 일은 아니었으니..

워드프레스로 이사는.. 계획중이나..
migraton tool을 못찾아서.. 언제 될지는 미지수..

변경사항

  • 댓글과 방명록에 대한 로봇 스팸 방지 강화
  • 레퍼러 로그에 필터링(ip, host, url)이 적용되어 스팸 방지 강화
  • RSS의 author에 이메일 노출 제거 (확실한 해결책이 결정되기 전까지는 이 방법을 유지하고자 합니다)
  • Tag Handling Plugin API를 전체 스킨 내용에 적용
  • 하위 버전 MySQL에서 중복된 랜덤 태크 출력 오류 수정
  • 블로그 설명 초기화 지원 및 특별한 조건에서 레이아웃이 깨지는 오류 수정
  • 분류명에 %, ? 등의 특수문자가 들어올 경우 링크 오류 수정
  • MySQL 5 및 일부 MySQL 환경에서 로그인 불가, 설치 불가, 데이터 복원 등의 문제 해결
  • 쥬크박스에서 경로까지 포함되어 표시되는 오류 수정
  • 이메이징 전체화면으로 감상시 PHP 경로 오류 수정
  • 사용자 초대시 메일발송이 안될 경우를 위해 비밀번호 표시 (임시로 이 방법을 지원합니다)
  • 부정확한 댓글 갯수 표시 오류 수정
    이미 잘못 저장된 댓글 개수를 보정하기 위해서는 "블로그URL/owner/data/recovery"를 실행시켜 주십시오.(다음 배포판부터 메뉴에 추가하도록 하겠습니다.)
  • 일별 방문자 통계 표시 방법 변경
  • 리더 개선 (계속 진행 중입니다)
  • 일부 방명록 데이터 중복 백업 오류 수정
  • 트랙백 IP주소 데이터 백업 누락 오류 수정
  • 데이터 복원시에 스킨이 존재하지 않더라도 스킨 설정 복원
  • 블로그 설정 일부 항목 데이터 복원 오류 수정
  • 설정 파일이 없을 경우 자동으로 셋업 실행
