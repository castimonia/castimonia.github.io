Powerpoint 인쇄 해상도 조정

innominata 5월 12, 2007

요약

loadTOCNode(1, 'summary');

이 문서에서는 Microsoft Office PowerPoint 2003에 대한 새 레지스트리 값을 추가하여, PowerPoint 2003에서 내보내는 슬라이드의 해상도 dpi(인치당 도트 수 설정)를 변경하는 방법을 단계별로 설명합니다.

참고 다음 표에서는 그림으로 내보내는 슬라이드에 대한 기본 설정을 보여 줍니다.

픽셀dpi(인치당 도트 수)
960 x 72096dpi(가로 및 세로)

레지스트리 설정 추가

loadTOCNode(2, 'summary');
기본값인 96dpi보다 높은 해상도의 그림으로 슬라이드를 내보내려면 레지스트리 값을 추가해야 합니다. 다음 단계에 따라 레지스트리 값을 추가하십시오.

경고 레지스트리 편집기를 잘못 사용하면 심각한 문제가 발생할 수 있으며 문제를 해결하기 위해 운영 체제를 다시 설치해야 할 수도 있습니다. Microsoft는 레지스트리 편집기를 잘못 사용하여 발생하는 문제에 대해 해결을 보증하지 않습니다. 레지스트리 편집기 사용에 따른 모든 책임은 사용자에게 있습니다.

1.Microsoft Windows 프로그램을 종료합니다.
2.시작을 누르고 실행을 누릅니다.
3.열기 상자에 regedit를 입력한 다음 확인을 누릅니다.
4.레지스트리를 확장하여 다음 키를 찾습니다.
HKEY_CURRENT_USERSoftwareMicrosoftOffice11.0PowerPointOptions
5.Options 키를 선택한 상태에서 편집 메뉴의 새로 만들기를 가리킨 다음 DWORD 값을 누릅니다.
6.ExportBitmapResolution을 입력한 다음 Enter 키를 누릅니다.
7.ExportBitmapResolution을 선택한 상태에서 편집 메뉴의 수정을 누릅니다.
8.다음 표를 참조하여 값 데이터 상자에 원하는 해상도 값을 입력합니다.

참고 PowerPoint 2003에서 내보낼 수 있는 최대 해상도 설정은 307dpi입니다.

9.10진수를 누른 다음 확인을 누릅니다.
10.파일 메뉴에서 끝내기를 눌러 레지스트리 편집기를 종료합니다.


PowerPoint 슬라이드를 그림으로 내보내기

loadTOCNode(2, 'summary'); PowerPoint 슬라이드를 그림으로 내보내려면 다음 단계를 수행하십시오.

1.PowerPoint를 시작한 다음 슬라이드 프레젠테이션을 엽니다.
2.내보낼 슬라이드를 엽니다.
3.파일 메뉴에서 다른 이름으로 저장을 누릅니다.
4.파일 형식 상자에서 슬라이드를 내보낼 형식을 선택한 다음 저장을 누릅니다.

예를 들어, 파일 형식 상자에서 다음 중 하나를 선택합니다.
GIF(Graphics Interchange Format) (.gif)
JPEG 파일 교환 형식 (*.jpg)
PNG 형식 (*.png)
TIFF(Tag Image File Format) (*.tif)
장치 독립적 비트맵 (*.bmp)
Windows 메타파일 (*.wmf)
확장 Windows 메타파일 (*.emf)


참고 저장 위치 상자에서 위치를 변경하여 그림을 저장할 위치를 변경할 수도 있습니다. 파일 이름 상자에서 이름을 변경하여 그림 이름을 변경할 수도 있습니다.

제한 사항

loadTOCNode(2, 'summary'); Microsoft Office PowerPoint 2003에서 그림을 내보낼 때 사용하는 해상도를 변경하기 위해 레지스트리에서 ExportBitmapResolution 레지스트리 값을 설정할 때는 다음과 같은 몇 가지 제한 사항을 염두에 두어야 합니다. Office PowerPoint 2003에서 내보낼 때 사용하는 최대 해상도 설정은 슬라이드의 가장 긴 가장자리를 기준으로 3072픽셀입니다. 예를 들어, 표준 10x7.5인치 슬라이드에 사용될 수 있는 최대 DPI 값은 307이므로 최대 해상도 설정은 10x307 = 3070픽셀이 됩니다. 3070픽셀은 제한 값인 3072를 초과하지 않습니다. 표준 슬라이드의 DPI 값을 307보다 높게 설정하면 제한 값인 3072로 되돌려집니다.

10진수 값픽셀(가로 x 세로)dpi(가로 및 세로)
3073072 x 2304307dpi

참고 제한 값인 3072픽셀은 프로그래밍 방식으로 슬라이드를 저장할 때도 적용됩니다. 지정된 픽셀로 슬라이드를 내보내도록 작성된 코드에서도 해당 픽셀 값이 3072로 제한됩니다. 예를 들어, ActiveWindow.Selection.SlideRange(1).export "c:filename.jpg","JPG",4000,3000과 같은 코드로 그래픽을 프로그래밍 방식으로 내보내면 해당 그래픽은 3072x2304픽셀로 내보내집니다.
