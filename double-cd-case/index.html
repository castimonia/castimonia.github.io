Double CD case

innominata 9월 30, 2004

A4 or letter size paper.
A4지나 편지 크기의 종이를 준비하세요.

You can print a label as shown
당신은 그림과 같은 곳에 라벨을 출력해도 됩니다.

C에서 A로 접은후,
방향 잡은후..

Fold B to D, unfold
B에서 D로 접은후, 다시 폅니다.

Fold B and D between one third and one fourth to the center.
B와 D를 접는데, 중간에서부터 1/3과 1/4의 사이로 접습니다.

One fourth if using letter size.
1/4는 당신이 편지크기의 종이를 사용할때 얘기입니다.

Fold A and C down - this isn't symmetrical
A와 C를 밑으로 접습니다.. 이것은 대칭이 아닙니다.

Refold step 2, inserting D into B.
2번째처럼 다시 접고, D를 B안에 넣습니다.

Pull corner C out and insert it into the pocket behind
C의 끝부분을 빼시고, 주머니 뒤로 안으로 넣습니다.
