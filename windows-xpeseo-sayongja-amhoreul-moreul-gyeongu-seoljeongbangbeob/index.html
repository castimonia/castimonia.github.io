Windows XP에서 사용자 암호를 모를 경우 설정방법

innominata June 7, 2006

1. 해결방법

가. 사용자 암호 삭제(환경설정)

- Windows XP Home Edition 부팅시 F5키를 누른후 Safemode(안전모드)로 부팅
- Login in 시 administrator로 로그온을 하여 바탕화면으로 들어갑니다.
- 제어판을 선택 사용자 계정에서 암호를 제거하시면 됩니다.

나. administrator로 로그온시 설정해둔 암호를 모를경우 (안전모드)

- 복구 콘솔이 설치되어 있거나 ,
- Windows XP Home Edition Boot Disk이용
- Windows 98SE 부팅 디스켓을 이용해서 (FAT32일경우)
- windows\system32\config\sam 파일을 삭제 후 안전모드로 들어가시면 됩니다.
